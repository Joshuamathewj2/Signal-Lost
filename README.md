# SIGNAL LOST

A 2D side-view platformer stealth-exploration puzzle game built in Godot Engine 4.4+.

> You are a tiny robot in an abandoned facility. The world is pitch black. You see only by emitting sonar pulses, but enemies hear every pulse. Seeing reveals your position.
